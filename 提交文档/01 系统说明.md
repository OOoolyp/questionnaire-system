# 基于 MongoDB 的问卷系统说明

本系统完成课程第一阶段的在线问卷业务：注册登录、创建与编辑草稿、配置校验和跳转、发布分享、登录填写、保存答卷、查看统计。

## 2 角色与使用流程

注册用户既可以创建问卷，也可以填写他人的已发布问卷。系统没有单独的管理员角色。管理、答卷和统计接口始终验证问卷归属；其他用户不能查看创建者的管理数据。填写者必须登录，匿名仅表示对创建者隐藏身份。

创建者流程：注册或登录 → 创建草稿 → 修改基本信息 → 添加题目与校验限制 → 配置跳转 → 填写预览 → 发布并选择截止时间 → 复制分享链接 → 查看答卷及统计 → 关闭问卷。

填写者流程：打开分享链接 → 登录或注册 → 按当前路径回答 → 修正提示的错误 → 提交 → 查看成功回执。前端按整页滚动显示当前路径上的题目，上游答案改变后清除被跳过题目的输入。

## 3 功能与实现位置

| 功能       | 当前行为                                           | 主要实现                             |
| ---------- | -------------------------------------------------- | ------------------------------------ |
| 注册登录   | Argon2 密码哈希；JWT 有效期 30 分钟                | app/security.py、app/main.py         |
| 问卷管理   | 仅管理本人问卷；草稿基本信息局部修改               | app/models.py、app/main.py           |
| 题目编辑   | 单选、多选、文本、数字；添加、替换、删除、题前插入 | app/questions.py、frontend/editor.js |
| 规则配置   | 单选匹配、多选完全匹配、数字比较                   | app/jumps.py                         |
| 发布关闭   | 草稿发布后锁定；截止或关闭后拒绝新提交             | app/submissions.py                   |
| 答卷保存   | 一次成功提交保存一个独立文档                       | app/submissions.py                   |
| 数据统计   | 整卷、单题、填空分页；实时 MongoDB 聚合            | app/statistics.py                    |
| 页面交互   | 正式工作台、整页填写、未保存提醒                   | frontend/                            |
| 调试与测试 | Swagger、真实 MongoDB 集成测试、前端逻辑测试       | /docs、tests/                        |

## 4 环境与启动

开发环境使用 Windows、conda base、Python 3.12。主要依赖固定在 requirements.txt：FastAPI 0.143.3、Uvicorn 0.54.0、PyMongo 4.17.0、Pydantic 2.10.3、PyJWT 2.15.1、pwdlib 0.3.1、python-multipart 0.0.32。前端使用原生 HTML、CSS、JavaScript，无需构建或安装 npm 依赖。运行前需另行安装并启动 MongoDB。

在项目根目录执行：

```powershell
conda activate base
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

| 地址                         | 用途                            |
| ---------------------------- | ------------------------------- |
| http://127.0.0.1:8000/       | 自动进入正式前端 /ui/           |
| http://127.0.0.1:8000/docs   | Swagger 调试页面                |
| http://127.0.0.1:8000/health | 数据库连接检查                  |
| /ui/# /fill/{shareToken}     | 浏览器填写页面                  |
| /survey/{share_token}        | 需登录的填写数据 API，返回 JSON |

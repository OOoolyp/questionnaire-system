## 1 环境与结果

本轮执行日期为 2026 年 10 月 18 日，后端使用 conda base、Python 3.12、真实 MongoDB。测试以 FastAPI TestClient 调用接口，无需启动另一个 Uvicorn；每轮使用随机命名的独立数据库，不写业务数据库。测试创建的数据在结束时清理。

```powershell
conda activate base
python -m pip install -r requirements-dev.txt
python -X utf8 -m unittest discover -s tests -v
node --test tests/frontend_logic.test.mjs tests/unsaved_state.test.mjs
```

Node 仅用于前端逻辑测试，正式前端运行不需要 Node。MongoDB 必须先启动。

### 2 进行局域网多设备端到端功能测试

本机服务监听`0.0.0.0:8000`，其他设备可通过服务器内网 IP 打开分享链接，登录、填写并提交；创建者查看答卷和统计。

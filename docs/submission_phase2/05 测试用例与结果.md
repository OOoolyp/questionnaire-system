## 2 执行方法与数据保留

在项目目录、已安装依赖且 MongoDB 正在运行时执行：

```powershell
conda activate base
python -m pip install -r requirements-dev.txt
$env:MONGODB_URI='mongodb://localhost:27017'
python -X utf8 -m unittest discover -s tests/backend -v
node --test tests/frontend/*.test.mjs
```

后端每个测试类或用例使用随机命名的隔离库，不写入展示库或普通业务库。按照本阶段要求，默认保留测试结束后的数据；仅显式设置 `$env:KEEP_TEST_DATA='0'` 才执行结束清理。为保证独立性，部分旧测试类仍在方法之间重置自己的夹具，因而保留的是这些类最后的状态；统计测试按方法独立建库，保留各方法最终数据。

本轮本地原始记录在 `var/phase2-backend-tests.log`、`var/phase2-frontend-tests.log`，环境失败首轮记录另存于 `var/phase2-backend-initial-environment-error.log`。var 是忽略提交的本地运行目录；提交说明不依赖这些文件一定随项目分发，可用上述命令重现。
